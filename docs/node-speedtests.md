# 节点测速

管理员可在“节点测速”页面通过真实节点代理测试下行速度、连接延迟和出口 IP。页面支持
主控本机与家庭测速端两种来源、单线程或 8 线程、批量排队、最近结果和节点历史记录。
该功能免费，不请求许可证服务。

## 使用前提

1. 节点必须启用，并已通过正常的服务器、入站和节点流程创建。
2. 至少有一个启用的套餐用户获得该节点，且用户凭据已经下发。测速只复用现有已签发
   凭据，不生成伪造用户或额外长期密码。
3. 主控本机测速仅支持 Linux `amd64` 和 `arm64`。首次使用会按固定 URL、大小与
   SHA-256 下载 Mihomo v1.19.30；Snell v6 自动改用 sing-box v1.14.0。
4. 下载测速会占用节点流量。正式使用前应确认套餐、线路和上游流量策略允许测试。

页面右上方会显示本机测速核心状态。第一次测速需要准备运行时，因此排队后可能比后续
测试多等待一段下载时间。下载、解压和运行目录均位于应用私有状态目录；压缩包和正文
有上限，摘要不匹配时不会执行。

## 测速方式

- **速度测试**：默认约 8 秒，通过节点代理下载 HTTPS 测试正文并计算下行 Mbps，随后
  测量 Google 静态资源延迟和出口 IP。
- **仅测延迟**：通过节点代理请求 Cloudflare `204` 端点三次，取最快两次的均值。
- **单线程**：更接近一个连接的实际表现。
- **8 线程**：观察聚合带宽。线程数和来源只保存在当前浏览器，换设备不会继承。
- **批量测速**：可以同时提交多个节点，但同一主控或同一家庭测速端会串行执行，避免
  相互抢占带宽。结果由后台异步保存，页面在运行时约每 1.5 秒刷新。

每条记录保存节点、来源、状态、下行、延迟、出口 IP、测试正文大小和时间。失败记录只
保存固定错误码，不保存代理配置、用户凭据、配对令牌或远端正文。

## 家庭测速端

家庭测速端适合从家庭宽带或另一网络观察节点表现。点击“新建测速端”，输入名称后会显示
一次性配对令牌和 Linux/Windows 安装命令。命令固定使用官方
[`speedtest-v0.1.5`](https://github.com/MMWOrg/mmwX-plugins/releases/tag/speedtest-v0.1.5)
安装脚本的精确提交，不跟随移动分支。

测速端主动连接主控的 `/api/speedtest/tester/ws`。主控必须有可公开访问且证书可信的
HTTPS/WSS 地址；仅 SSH 隧道或私有地址不能供外部家庭测速端连接。连接后页面会显示在线
状态、版本和能力。令牌只显示一次，数据库只保存摘要：

- 丢失令牌时使用“轮换令牌”，旧连接会立即断开；
- 不再使用时点击“撤销”，令牌和连接失效，历史记录保留；
- 同一个测速端的新连接会替换旧连接；
- 家庭测速端任务有串行锁、消息大小限制和超时，断线不会把代理凭据写入历史或错误响应。

官方家庭测速端 v0.1.5 使用 Mihomo 执行任务。Open Node 主控本机额外支持由 sing-box
执行 Snell v6；这不会改变官方测速端的线协议。

## 备份与安全边界

测速端记录、令牌摘要和测试历史随 SQLite 一致快照备份；运行时二进制可按固定摘要重新
下载，不需要放入备份。恢复后，旧家庭测速端令牌仍属于敏感身份，应按灾难恢复策略决定
是否统一轮换。后台排队或运行中的任务不作为可恢复作业重放。

本功能不绕过订阅权限或 Agent 权限，也不证明节点对所有地区、运营商或客户端都可用。
真实带宽结果受测速来源、上游限速、出口、测试站和当时网络拥塞影响。
