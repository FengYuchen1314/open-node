# 浏览器首次初始化

新安装可以在中文页面创建首个管理员，同时设置昵称、邮箱、头像地址、浏览器标题和
页面品牌文字。
流程参考[官方新手教程](https://miaomiaowux.com/docs/tutorial/#4-初始化)及固定版本
`miaomiaowuX/internal/handler/setup.go`。Open Node 默认允许在可信 HTTPS 页面直接创建
首个管理员，不需要初始化凭证，也没有默认密码、激活码或许可证要求。管理员创建前属于
先到先得边界：任何能访问初始化页面的人都可能成为管理员，请在安装完成后立即初始化。

## 安装与打开页面

默认 GitHub 安装脚本会在应用和受管公网 HTTPS 都通过检查后显示初始化地址，不签发普通
初始化凭证。全新安装默认地址是 `https://<公网 IP>:58090`；IPv6 地址使用
方括号。若安装时提供了可选 `OPEN_NODE_PUBLIC_HOSTNAME`，域名 HTTPS 地址成为
canonical URL，IP HTTPS 地址仍可使用。

明确以 `OPEN_NODE_PUBLIC_IP=off` 关闭 IP 入口，或同时设置
`OPEN_NODE_PUBLIC_IP=off OPEN_NODE_PUBLIC_HOSTNAME=` 关闭全部受管公网入口时，
可通过 SSH 隧道访问宿主回环端口。宿主/容器端口均为 `62031`：

```bash
ssh -L 62031:127.0.0.1:62031 root@SERVER_IP
```

随后访问 `http://127.0.0.1:62031`。填写管理员用户名、密码、资料及站点名称，
勾选新安装确认后提交。用户名为 1–64 个英文字母、数字或 `_.@-`；密码为
12–1024 个 Unicode 字符，首尾空格原样保留。浏览器标题最多 80 个字符，
品牌文字最多 40 个字符，均为纯文本。

昵称、邮箱和头像均可留空；空昵称保存为管理员用户名。邮箱只是资料字段，不作为登录
凭据。头像使用外部 HTTPS URL，最长 2048 个字符，不接受明文 HTTP、本地文件、URL
内嵌用户名/密码或控制字符，主控不会代为下载或上传图片。初始化后可以在“系统设置 →
管理员资料”修改这三项。保存带版本号，旧页面不会覆盖其他会话刚保存的资料。

完成后点击“前往登录”，页面重新加载站点名称，再使用刚设置的账户登录。
初始化不自动建立登录会话，也不绕过已有双因素认证策略。

初始化页面不会生成或保存普通初始化凭证。请勿长时间让新实例保持未初始化状态；如果暂时
不能创建管理员，应先在防火墙限制 `58090`，或安装时关闭公网入口并通过 SSH 隧道操作。

## 仅用于备份恢复的凭证

普通创建首个管理员不需要下面的命令。只有尚未初始化的新实例要从本项目 v1 备份恢复时，
才运行已下载并审阅的安装脚本签发 30 分钟一次性恢复凭证：

```bash
sudo bash /path/to/reviewed/install.sh setup
```

若首次安装指定了 `OPEN_NODE_CONFIG_DIR`，本次仍须传入相同目录。
脚本会核对安装清单、源码、镜像、数据卷和服务健康，再生成恢复凭证。重复签发立即使旧
凭证失效，不会修改管理员密码或站点名称。

手动 Compose 部署可在使用同一配置文件、同一数据卷的运行中容器内执行：

```bash
docker compose exec -T open-node open-node-admin prepare-setup
```

直接运行后端时，使用与服务相同的数据库设置运行 `open-node-admin prepare-setup`。
可加 `--json` 供本地自动化读取；输出仍含恢复秘密，不应进入公共日志。不存在 HTTP
签发凭证接口。

## 保留终端初始化

`OPEN_NODE_CREATE_ADMIN` 支持以下值：

| 值 | 新安装后的行为 |
| --- | --- |
| `auto`（默认） | 没有密码文件时显示浏览器初始化地址；提供密码文件时在终端创建管理员 |
| `web` | 显示浏览器初始化地址，不能同时指定密码文件 |
| `1` | 保留终端密码确认或私有密码文件流程 |
| `0` | 跳过提示；稍后直接打开初始化页或运行 `create-admin` |

无人值守创建仍使用 root 所有、仅自身可读的 `OPEN_NODE_ADMIN_PASSWORD_FILE`，
不会把密码放进命令行参数。具体用法见[部署指南](deployment.md)。
`create-admin` 和 `open-node-admin create` 的原有行为保留。

## 错误与恢复边界

提交被拒绝后，页面清空密码并重新读取状态。若网络中断，页面只查询，
不会自动重复创建；已初始化时转到登录入口。重新读取也失败时，输入表单保持关闭。
初始化请求每个来源每分钟最多 10 次，超出后至少等待一分钟。

管理员、管理员资料、站点文字和永久初始化标记在同一数据库事务内提交。
重复请求和终端创建竞态最多产生一个管理员。已存在管理员、完成标记或已恢复的
实例不能重新开放普通初始化；删除管理员记录也不会重新开放。忘记密码使用
[本地恢复命令](administrator-access.md)，不要删除数据库。

本功能面向新建单机 SQLite/PostgreSQL 部署。有效恢复凭证可在页面选择“从备份恢复现有实例”，
上传本项目 v1 age/明文备份；准备成功后由容器重启激活，再使用备份中的管理员复核。
恢复不会先创建空管理员，并使恢复凭证失效。完整边界见
[浏览器/离线恢复及首次启动复核](backups.md)。PostgreSQL 配置和 DNS 账户配置仍未包含。
浏览器内恢复复用当前已验证入口；另建 Compose 项目进行离线恢复时必须显式提供一个
未占用的 `OPEN_NODE_RESTORE_HTTP_PORT`，不会继承 62031、58090 或生产端口。
