# 浏览器首次初始化

新安装可以在中文页面创建首个管理员，同时设置昵称、邮箱、头像地址、浏览器标题和
页面品牌文字。
流程参考[官方新手教程](https://miaomiaowux.com/docs/tutorial/#4-初始化)及固定版本
`miaomiaowuX/internal/handler/setup.go`。Open Node 额外要求服务器终端签发的
一次性凭证，避免公开空面板被其他人抢先注册。没有默认密码、激活码或许可证要求。

## 安装与打开页面

默认 GitHub 安装脚本会在服务通过健康检查后显示初始化凭证，有效期 30 分钟。
通过 SSH 隧道打开面板，或使用[公网一键部署](public-deployment.md)已经验证的
可信 HTTPS 地址。默认端口的隧道示例：

```bash
ssh -L 8080:127.0.0.1:8080 root@SERVER_IP
```

随后访问 `http://127.0.0.1:8080`。填写终端凭证、管理员用户名、密码、资料及站点名称，
勾选新安装确认后提交。用户名为 1–64 个英文字母、数字或 `_.@-`；密码为
12–1024 个 Unicode 字符，首尾空格原样保留。浏览器标题最多 80 个字符，
品牌文字最多 40 个字符，均为纯文本。

昵称、邮箱和头像均可留空；空昵称保存为管理员用户名。邮箱只是资料字段，不作为登录
凭据。头像使用外部 HTTPS URL，最长 2048 个字符，不接受明文 HTTP、本地文件、URL
内嵌用户名/密码或控制字符，主控不会代为下载或上传图片。初始化后可以在“系统设置 →
管理员资料”修改这三项。保存带版本号，旧页面不会覆盖其他会话刚保存的资料。

完成后点击“前往登录”，页面重新加载站点名称，再使用刚设置的账户登录。
初始化不自动建立登录会话，也不绕过已有双因素认证策略。

凭证只在终端输出中显示，不写入 URL、安装清单或浏览器存储。不要分享截图、
终端录屏或包含凭证的安装日志。数据库只存储凭证摘要，使用后立即清除。

## 凭证过期或丢失

安装器管理的部署，运行已下载并审阅的安装脚本：

```bash
sudo bash /path/to/reviewed/install.sh setup
```

若首次安装指定了 `OPEN_NODE_CONFIG_DIR`，本次仍须传入相同目录。
脚本会核对安装清单、源码、镜像、数据卷和服务健康，再生成凭证。
重复签发立即使旧凭证失效，不会修改管理员密码或站点名称。

手动 Compose 部署可在使用同一配置文件、同一数据卷的运行中容器内执行：

```bash
docker compose exec -T open-node open-node-admin prepare-setup
```

直接运行后端时，使用与服务相同的数据库设置运行 `open-node-admin prepare-setup`。
可加 `--json` 供本地自动化读取；输出仍含秘密，不应进入公共日志。
不存在 HTTP 签发凭证接口。

## 保留终端初始化

`OPEN_NODE_CREATE_ADMIN` 支持以下值：

| 值 | 新安装后的行为 |
| --- | --- |
| `auto`（默认） | 没有密码文件时签发浏览器凭证；提供密码文件时在终端创建管理员 |
| `web` | 签发浏览器凭证，不能同时指定密码文件 |
| `1` | 保留终端密码确认或私有密码文件流程 |
| `0` | 跳过；稍后运行 `setup` 或 `create-admin` |

无人值守创建仍使用 root 所有、仅自身可读的 `OPEN_NODE_ADMIN_PASSWORD_FILE`，
不会把密码放进命令行参数。具体用法见[部署指南](deployment.md)。
`create-admin` 和 `open-node-admin create` 的原有行为保留。

## 错误与恢复边界

提交被拒绝后，页面清空凭证和密码并重新读取状态。若网络中断，页面只查询，
不会自动重复创建；已初始化时转到登录入口。重新读取也失败时，输入表单保持关闭。
初始化请求每个来源每分钟最多 10 次，超出后至少等待一分钟。

管理员、管理员资料、站点文字、永久初始化标记及凭证消费在同一 SQLite 事务内提交。
重复请求和终端创建竞态最多产生一个管理员。已存在管理员、完成标记或已恢复的
实例不能重新签发凭证；删除管理员记录也不会重新开放初始化。忘记密码使用
[本地恢复命令](administrator-access.md)，不要删除数据库。

本功能面向新建单机 SQLite 部署。有效初始化凭证也可在页面选择“从备份恢复现有实例”，
上传本项目 v1 age/明文备份；准备成功后由容器重启激活，再使用备份中的管理员复核。
恢复不会先创建空管理员，并使初始化凭证失效。完整边界见
[浏览器/离线恢复及首次启动复核](backups.md)。PostgreSQL 配置和 DNS 账户配置仍未包含。
主控 HTTPS 可由根安装器在域名解析就绪后接入。
