## 可以修改什么

管理员登录后，打开“系统设置”，可以修改两项文字：

| 设置 | 显示位置 | 长度 |
| --- | --- | --- |
| 浏览器标题 | 管理员登录、管理后台、用户中心的标签页标题后缀 | 1–80 个 Unicode 码点 |
| 页面品牌文字 | 登录页、管理导航、后台标题和用户中心页头 | 1–40 个 Unicode 码点 |

默认均为 `Open Node`。例如，浏览器标题设为“示例站点”后，系统设置页的标签页
标题为“系统设置 - 示例站点”。当前页面保存成功后会同步更新；其他已打开的
标签页需要刷新，系统设置页也可以点击“重新读取站点文字”。没有跨标签页实时推送。

这两项文字公开可见，未登录用户也能读取。不要填入密码、Token、订阅链接或其他
秘密。读取公开名称不附带 Cookie、Authorization 或 CSRF，也不会把名称发到外部网站。

## 保存与恢复默认

1. 等待页面读取已保存配置，再编辑名称。
2. 检查“有未保存的草稿”提示，点击“保存站点文字”。只有保存成功才会更新站点。
3. 如需恢复原名称，点击“恢复默认草稿”，再点击保存。恢复草稿本身不改数据库。
4. 点击“重新读取站点文字”会丢弃未保存的草稿，读取当前数据库中的版本。

名称只接受文字字符串。系统先检查原始输入，再去掉首尾空白，按 Unicode 码点
计算长度；emoji 可能包含多个码点。拒绝空名称、只有空白或连接符的名称、控制
字符、换行和隐藏的双向控制字符，保留合法中文、emoji 和组合文字，不做 NFC 归一化。

HTML 样式的输入也只作为文字显示，不能插入图片、链接、脚本或样式。长名称在
正文和侧栏换行，空间有限的页头显示省略号，并保留完整名称提示。

## 并发修改和不确定的结果

页面读取配置时会取得版本号。保存需要提交该版本号；如果另一位操作者或另一个
标签页先保存了新版本，本次保存会返回冲突，不覆盖新值。页面重新读取后，请核对
当前配置，再决定是否重新修改。每次成功保存都增加一次版本号，包括保存相同值。

如果网络断开、服务返回异常或保存回执无效，页面不能据此判断“保存成功”或
“完全没有保存”。它只会重新读取当前配置并显示警告，不自动重复提交。重新读取
也失败时，保存保持不可用，直到手动读取成功。离开页面不代表已经到达服务器的
保存被取消；重新进入后以读取到的配置为准。

过期的读取响应不能覆盖当前页面已经确认的新版本。未保存的草稿不改变全局标题，
退出登录或切换身份后，旧请求也不能把结果写进新身份的设置页。

## 权限和故障处理

公开读取只返回两个名称及固定的 `license_required: false`，不返回管理员配置、
版本、会话、数据库路径或密钥。管理接口要求管理员会话；保存还要求既有的 Origin
和 CSRF 检查。普通订阅用户不能修改站点名称。

页面初次加载时，若公开配置读取失败或格式异常，会保留默认的 `Open Node` 名称，
不显示服务器的原始错误。已经确认的新配置不会被旧请求的失败重置。
管理页会显示固定的中文错误。数据库中的品牌记录损坏
时不会自动重置或伪报保存成功；应由操作者检查存储。仅品牌设置不可用不会阻止
其余应用初始化。

## 数据保留与本期边界

两个名称和版本号存放在现有 SQLite 数据库的独立 `site_branding_settings` 表中，
保存两个值使用同一个事务。重启保留名称和版本，不新增品牌专用密钥。

品牌设置随数据库备份恢复；备份整套服务时，仍必须保留通知、证书、外部订阅、
TOTP 等功能所需的完整数据卷和密钥。不要把运行中的 SQLite 主文件单独复制当成
一致备份。本页没有下载备份或在线恢复按钮，现有停服数据卷备份流程见
[部署说明](deployment.md)。恢复旧备份后，请刷新浏览器再修改设置。

本期只支持 SQLite 品牌存储，不声称具备 PostgreSQL 品牌配置能力。以下内容不变：

- 公共 Probe 使用自己的标题和设置；Probe-only 构建不请求站点品牌。
- 技术说明中的 Open Node 名称、折叠侧栏的 `ON` 标识、TOTP issuer、健康检查身份。
- 通知正文、套餐、订阅、模板、Agent 命令和服务器配置。
- 环境变量、登录策略、CORS、TLS、许可证状态及其他安全设置。

尚未实现 Logo、背景图片、上传、自定义 HTML/CSS/JavaScript、公告、静默模式、
更新通道和任意键值配置。免费使用这些文字设置不需要 PRO、激活码或许可证服务；
这不代表完整官方系统设置已经实现。

## API

| 接口 | 说明 |
| --- | --- |
| `GET /api/v1/branding` | 匿名读取两个公开名称和固定免费标志 |
| `GET /api/v1/system-settings/branding` | 管理员读取名称和 `revision` |
| `PUT /api/v1/system-settings/branding` | 提交 `expected_revision`、`site_title`、`brand_title`；返回保存后的版本 |

写请求最多 4096 字节，只接受 UTF-8 JSON；拒绝未知字段、重复字段、非有限数字、
隐式类型转换和超范围版本。版本必须是 0–9007199254740991 的整数。
正常及错误响应均禁止缓存，不回显非法输入。

业务依据是固定官方源码中的
[branding.go](https://github.com/tajiaoyezi/miaomiaowuX/blob/c12ce653bc07fe30426b7dfcb85076974b7be0e0/internal/handler/branding.go)
以及[官方系统设置文档](https://miaomiaowux.com/docs/en/system-settings/)。
独立类型化存储、原子保存和错误处理是本项目的实现；详细差异见
[站点文字设计记录](system-settings-plan.md)。
