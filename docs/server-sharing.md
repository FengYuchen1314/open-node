# 服务器共享与联邦接入

Open Node 已提供免费的服务器共享。管理员可以把自己名下的一台 Agent 服务器
分享给另一套 Open Node 主控，也可以在当前主控接入别人分享的服务器。该功能没有
许可证、激活码或付费功能门槛。

## 拥有方

在“服务器共享”页面选择本地主控中的服务器，然后创建有限权限或完整权限分享。

- 分享令牌只在创建成功后显示一次，服务端只保存 SHA-256 摘要；每台服务器最多保留
  20 个有效分享。
- 有限权限分享只能读取自己创建的入站、创建新入站，以及修改或删除自己创建的入站。
  入站列表会按该分享的所有权过滤，不能读取或操作服务器上已有的其他入站。
- 完整权限分享可以调用当前 Agent 已实现并通过能力检查的子路由；它不会绕过 Agent
  能力门槛，也不会让尚未实现的命令变得可用。
- 吊销后令牌立即失效。管理员可选择同时创建清理命令，删除该分享曾成功创建的入站；
  清理通过现有耐久 Agent 命令执行，因此离线服务器会等待重连，而不是伪装成已删除。

## 接入方

在同一页面的“接入共享服务器”区域填写拥有方的 HTTPS 根地址、一次性收到的分享令牌、
本地显示名称及可选前缀。接入后它会以普通服务器卡片出现在服务器、流量、DDNS、探针和
配置工作区中，并带紫色“分享”标记。接入方可以：

- 查看拥有方公布的服务器在线状态、IPv4/IPv6、带宽、流量、Xray/Nginx 状态，以及
  CPU、内存、磁盘和累计网络指标；
- 等待后台每五秒自动刷新，也可以手动刷新状态并同步自己名下的入站；
- 在“配置工作区 → 运行时”把同步到的入站创建为普通节点，分配给套餐用户，并通过
  拥有方中继补齐或清理这些入站的用户凭据；
- 在服务器共享命令工作台按分享权限新增、编辑或删除自己的入站；
- 从当前主控移除接入记录。移除只删除本地记录，不会替拥有方吊销分享。

接入方不能编辑服务器元数据、启停或安装 Xray/Nginx、读取完整配置、直连 Agent、创建
隧道或再次分享。配置工作区因此只为分享服务器显示运行时节点与凭据页，其余 Agent
控制页隐藏；后端仍独立执行同样的权限检查，不能靠直接调用 API 绕过。

令牌使用持久化密钥加密后才写入数据库，API、列表和错误响应都不会回显明文。接入记录
使用修订号避免两个页面用旧状态互相覆盖。后台快照刷新不改变管理修订号，因此不会让
正在执行的移除或手动刷新因为五秒轮询而持续冲突。网络失败保留最后一次成功快照并退避，
不会把服务器伪装成已同步。

## 网络与安全边界

主控之间只接受 HTTPS。连接会先解析并固定到公开地址，校验证书和原始主机名，禁止
重定向、私网/回环/链路本地目标和超大响应。拥有方 API 使用 `X-Share-Token` 认证并做
登录尝试限流。管理操作优先使用官方 `X-Fed-KeyEx` / `X-Encrypted` 协议：双方交换临时
X25519 公钥，把分享令牌以 HMAC-SHA256 混入共享秘密，再按官方 `securechan-v1` 的
HKDF-SHA256 和双向 AES-256-GCM 信封加密。会话三十分钟过期，带序号和重放窗口；拥有方
不支持时自动降级为 HTTPS + 令牌。只有部署在可由另一主控访问的可信公网 HTTPS 地址时，
跨主控接入才可用。

请把 SQLite 数据库和数据库同目录下的 `federation/` 密钥目录作为一个整体备份。只恢复
数据库而丢失该目录后，已接入分享的令牌无法解密，需要删除后重新接入。

## 与固定官方实现的关系

本批参考 `miaomiaowuX` 固定提交
`c12ce653bc07fe30426b7dfcb85076974b7be0e0` 中的 `server_share.go`、
`federation.go`、`federated_add.go`、`federation_crypto.go` 和相关存储/轮询代码。
令牌摘要、有限/完整权限、入站归属及吊销清理等核心语义保持一致；Open Node 使用自己
已有的耐久 Agent 命令，不复制官方的五秒内存轮询器，也不复制 PRO 许可证限制。

当前实现同时支持两种方向：Open Node 接入官方拥有方时优先调用官方
`/api/federation/*` 加密协议，缺失时回退版本化接口；官方消费方也可以直接调用 Open Node
拥有方暴露的同名旧路径。Open Node 自身版本化接口保留耐久命令 ID 和轮询能力。

仍有以下明确差异：

- 官方把共享放在 PRO 许可证和 Reality 商业共享池中；Open Node 不复制许可证、激活、
  计费或商业资源池，功能始终免费。
- 当前 Agent 扫描能透传 Nginx 的安装/运行状态，但扫描协议本身没有单独的 Nginx 版本
  字段，因此界面不伪造版本号。
- Open Node 使用持久命令、失败不重放和备份写协调，不复制官方五秒内存命令等待器。

这些差异不影响新部署下的共享服务器、入站、节点和用户分配主流程，但不把免费实现描述
为官方商业服务的一比一复制品。
